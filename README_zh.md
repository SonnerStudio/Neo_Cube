**下一代 GameCube 仿真体验。**

Neo-Cube 是一款革命性的、周期精确的 GameCube 模拟器，原生构建在 **SSPL v9.5** 框架之上。通过其基于组件的混合架构（CBA），Neo-Cube 提供了绝对的性能、优质的用户界面和前所未有的网络功能。

> [!NOTE]
> **独家功能:** Neo-Cube 原生支持 **FlippyDrive Deluxe** 仿真！通过虚拟以太网附加组件直接从您的 PC/NAS 传输 ISO，并通过 P2P 在全球范围内畅玩局域网多人游戏。

## 🌟 核心功能
- **CBA:** 具有 CPU、GPU 和 DSP 同步执行的模块化核心。
- **Neo-Cube 电源模式：** 释放最大性能！此模式提供扩展内存和超优化的 Dolphin CPU 核心，以实现最高保真度和帧率。
  
  <img src="docs/powermode_config.jpg" alt="Power-Mode Config" width="800">

- **SSGE Vulkan 后端：** 与新的 SonnerStudioGraficEngine (`vulkan_backend.sspl`) 原生集成，实现完美渲染。
- **FlippyDrive 以太网附加组件：** 虚拟 LAN/NAS 模拟 (`ethernet_addon.sspl`)，无缝加载 ISO 游戏。
- **原生 DVD 接口：** 用于 ISO 文件系统的全新周期精确解析器 (`dvd_interface.sspl`)。
- **Neo-Cube Live (NCL):** 通过 LAN 隧道实现在线多人游戏。
- **CubeWave VoIP:** 操作系统集成的语音聊天，用于创建派对。
- **Flippy-OS 豪华模式:** 直接启动到原始的 CubeBoot 固件。
- **高级“Neo-XMB”仪表板：** 令人惊叹的 4K 拟物化深色模式用户界面，以流畅的 60FPS 运行。专为最大独家性而打造。
